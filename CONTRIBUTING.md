AfiaHealth Contributing Guide

# Contributing to AfiaHealth 🏥
===

# 

# Thank you for your interest in contributing to AfiaHealth — Africa's premier healthcare discovery platform!

# 

# \## Getting Started

# 

# 1\. Fork the repository

# &#x20;  - Click the "Fork" button on https://github.com/Meet-hybrid/afiahealth

# 

# 2\. Clone your fork

# &#x20;  - git clone https://github.com/YOUR\_USERNAME/afiahealth.git

# 

# 3\. Create a new branch

# &#x20;  - git checkout -b feature/your-feature-name

# 

# 4\. Make your changes and commit

# &#x20;  - git commit -m "feat: describe what you did"

# 

# 5\. Push to your fork

# &#x20;  - git push origin feature/your-feature-name

# 

# 6\. Open a Pull Request on GitHub

# 

# \## Branch Naming Rules

# \- feature/hospital-map     → new features

# \- fix/login-bug            → bug fixes

# \- chore/update-deps        → maintenance

# \- docs/update-readme       → documentation

# 

# \## Commit Message Rules

# \- feat(scope): add new feature

# \- fix(scope): fix a bug

# \- chore(scope): maintenance task

# \- docs(scope): documentation update

# 

# \## Tech Stack

# \- Backend: Java 17, Spring Boot 3.2, MySQL 8, Redis

# \- Frontend: Vue 3, Vite, Tailwind CSS, Pinia

# \- Auth: JWT (access + refresh tokens)

# \- Maps: Google Maps API

# 

# \## Areas You Can Contribute To

# \- Add more Nigerian states and hospital data

# \- Improve the Arabic/French/Hausa/Yoruba translations

# \- Add more health article content

# \- Improve mobile responsiveness

# \- Write unit and integration tests

# \- Improve the admin dashboard analytics

# \- Add more insurance provider integrations

# 

# \## Code Style

# \- Java: follow Google Java Style Guide

# \- Vue: use Composition API with script setup

# \- CSS: use Tailwind utility classes only

# \- Always add comments for complex logic

# 

# \## Need Help?

# Open an issue on GitHub or email: contribute@afiahealth.africa

# 

# \## Code of Conduct

# Be respectful, inclusive, and professional.

# This project is built for Africa — everyone is welcome.
