\## 🌍 About

AfiaHealth connects patients with verified hospitals, doctors,

pharmacies and emergency services across Nigeria and Africa.



\## ✨ Features

\- 🔍 Hospital search by location and specialty

\- 🚨 Emergency hospital finder with 24/7 filter

\- 👨‍⚕️ Doctor listings with telemedicine support

\- 📅 Appointment booking system

\- 🚑 Ambulance dispatch and tracking

\- 💊 Pharmacy locator with delivery support

\- ⭐ Verified patient reviews

\- 🌐 Multi-language: English, French, Hausa, Yoruba

\- 📊 Full admin dashboard



\## 🚀 Quick Start

\### With Docker

```bash

cp frontend/.env.example frontend/.env

docker compose up --build

```

Open http://localhost



\## 🛠 Tech Stack

| Layer | Technology |

|---|---|

| Frontend | Vue 3, Vite, Tailwind CSS, Pinia |

| Backend | Java 17, Spring Boot 3.2 |

| Database | MySQL 8.0 |

| Cache | Redis 7 |

| Auth | JWT access and refresh tokens |

| Maps | Google Maps API |

| Deploy | Docker and Nginx |
